## Pontos de atenção

- No PostgreSQL, um erro aborta a transação; use `SAVEPOINT` no app e nos testes que continuam depois do erro.
- `CURRENT_TIMESTAMP` é constante dentro da transação: use isso para testar 15:00, 60:00 etc. exatos.
- Entrada usa `FOR UPDATE SKIP LOCKED`; o índice único parcial é a segunda camada da regra de uma permanência aberta por veículo.
- Q03 usa `RANK()` e filtro `posicao <= 10`, não `LIMIT`, para não perder empate.
- Q07 pode devolver muitas vagas nunca usadas; teste a contagem e os códigos de fronteira.
- `04_indices.sql` cria os índices no schema principal; a medição antes/depois deve ser feita em schema separado para não derrubar os índices reais.
- Os scripts de init rodam só na primeira subida; use `docker compose down -v` para repetir do zero.
- No Java, `NUMERIC` vai como `BigDecimal`; `CallableStatement` precisa de `escapeSyntaxCallMode=callIfNoReturn`.
- Procedures nunca fazem `COMMIT`.
- O log de IA precisa de erros reais; não preencha com “a IA ajudou muito”.
