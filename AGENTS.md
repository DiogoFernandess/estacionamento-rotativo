# AGENTS.md — A3 Banco de Dados

## Projeto

**Estacionamento Rotativo Central** (fictício): 100 vagas de carro + 20 de moto, rotativo avulso, sem mensalistas. PostgreSQL 17 + Java 21 (Maven/JDBC) + JUnit 5 + Docker Compose.

**Fonte de verdade:** `decisions.md` (somente leitura para agentes/IA). **Plano de tarefas:** `atividades.md`. Se este arquivo divergir deles, os dois vencem.

**Estado atual:** Frente 0 concluída (estrutura/compose validado pelo grupo); `decisions.md` validado e congelado para agentes/IA. Os SQL em `postgresql/` e `procedures/` são **placeholders**; não trate como esquema final. Os serviços `testes` e `app` entram na Frente C.

- Ambiente: `config.md` (o que o computador precisa ter instalado para rodar)

## Regras que não podem ser quebradas

- Só PostgreSQL. Nunca use sintaxe Oracle (`VARCHAR2`, `NUMBER`, `SYSDATE`, `DUAL`, `ROWNUM` etc.). Use `ON DELETE RESTRICT` nas FKs, como manda o projeto.
- Tipos do projeto: `VARCHAR`, `INTEGER`, `NUMERIC(10,2)`, `TIMESTAMP`, `DATE`, `BOOLEAN`, `INTEGER GENERATED BY DEFAULT AS IDENTITY` para PKs.
- Constraints sempre nomeadas (`pk_`, `uk_`, `fk_`, `ck_`); todas as FKs com `ON DELETE RESTRICT`.
- **Procedures nunca fazem `COMMIT`**; quem chama controla a transação.
- Erros de negócio com prefixo `ESTAC-00x` e SQLSTATE `P0001`; o app traduz pelo prefixo.
- Todo SQL só vale depois de executado no banco de laboratório; registre a saída real.
- Nunca `DROP`, `TRUNCATE` ou `DELETE`/`UPDATE` sem `WHERE`; nunca contra banco que não seja o do laboratório.
- Sem dados pessoais reais, senhas reais ou chaves no repositório. Dados fictícios.
- Na aplicação, só bind (`?`); nunca concatenar valores.
- Não invente tempos de performance; cole o `EXPLAIN` real.
- Não crie tabela, coluna, consulta ou código de erro fora de `decisions.md`. Se faltar, pare e peça ao grupo; somente o grupo atualiza o arquivo.
- **`decisions.md` é somente leitura para agentes/IA.** Não use `edit`, `write`, `patch` nem comandos de shell para alterá-lo. Se algo faltar ou estiver errado, pare e pergunte ao grupo; a mudança é registrada no commit e no log de IA.
- Não faça push; o grupo publica. Registre no log de IA o pedido, o erro/omissão do agente e a correção do grupo.
- **Quem executa a tarefa preenche o `Dono` dela em `atividades.md`.** Ao concluir (ou assumir) uma tarefa, grave o nome de quem fez no campo `- **Dono:**`. Tarefa concluída sem Dono preenchido fica incompleta.

## Comandos

```bash
docker compose down -v
docker compose up -d --wait
docker compose run --rm testes
docker compose --profile apps run --rm app
docker compose exec postgres psql -U estacionamento -d estacionamento
```

## Modelo em uma linha

7 tabelas (`tipo_veiculo`, `vaga`, `veiculo`, `tarifa`, `permanencia`, `pagamento`, `auditoria_permanencia`); N:M `veiculo` ↔ `vaga` via `permanencia`; ocupação derivada; tarifa insert-only congelada por `tarifa_id`; auditoria por trigger.
